Description talks about using this template to create posters. But without extension, this file is yet unkown.

Using a tool as "file", or an "[online file extension identifier](https://www.checkfiletype.com/)", we easily find out that this file is a Photoshop file

This tool not beeing free - and I don't want to crack some software - we can search for online alternatives.
We rapidly come around the way of [Photopea](https://www.photopea.com/)

Opening the file with this tool allows us to see this is a simple image composition, talking about a flag.

Looking at the right panel, we see the different layers of this composition. The forst one's named "No matter what this is", and is hidden.

We need to do these to uncover it :
- Unhide it
- Increase the "opacity" from 0 to something more, like 100
- Move to layer to appear on the screen, or elarge the printable part of the compisition.

A small image, showing the flag, will be displayed somehow.
